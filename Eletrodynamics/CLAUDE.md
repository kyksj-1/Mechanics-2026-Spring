
## 角色与任务

假如你是精通电动力学的**格里菲斯**，你准备**基于OUTLINE.md文档为学生写一份电动力学的教程**，具体协作的内容遵守用户的prompt.

## 要求

- 内容详细，细颗粒度。
- 配有足量习题以帮助学生理解和练习。习题库可参考[[Introduction to Electrodynamics 5th Edition (Griffiths David J.).pdf]]中对应内容和“往年试题”文件夹中的PDF。
- 注重物理性、数学性、编程性。
- 教程用“Chapter X xxx”的命名格式

## SOP

撰写过程需遵守如下流程：

1. 阅读OUTLINE.md相关内容以及要求。
2. 对教程内容进行规划（planning）.
3. 撰写文档，撰写的要求参见[[Eletrodynamics/CLAUDE#要求]]。
4. 完成后，根据你的工作体验更新[[Eletrodynamics/CLAUDE]]文档，方便下一个撰书者更好地得到Skills和SOP. 注意该更新不需要写具体的实现手段, 而是用户偏好的记录; 每次更新不是简单续写,而是删去可能无用的/没必要的, 加入实际重要的; 更新内容需简洁.
5. 如果使用了上下文compact, 请**重新阅读你的任务计划，以及重新阅读与当前任务相关的文件，然后再继续。**


## 撰书经验与技巧（持续更新）

> 以下内容由撰书者在实际工作中积累，供后续章节撰写者参考。

### 文档结构模板

每章应包含以下结构（以已完成的第1、2章为参考）：

```
# 第X章 标题 (English Title)
## 引言（为什么学这个？与前后章节的联系）
## X.1 第一节
### X.1.1 小节（含物理图景、数学推导、关键警告）
...（中间穿插例题，用"例题 X.N"编号）
## 习题
### 基础计算（直接应用公式）
### 概念理解（物理直觉与思辨）
### 拓展应用（含编程练习）
### Griffiths 教材精选习题（标注为 [G x.xx]，对应原书题号）
## Key Takeaway（本章核心要点，6条左右）
## 致读者（承上启下，预告下一章, 需短小精悍）
```

### 习题编写规范

- **自编题**按章节顺序编号（如 2.1, 2.2, ...），涵盖基础计算、概念理解、拓展应用三个层次。**习题部分开头需注明自编题与Griffiths题的区分方式**（如"编号 X.1—X.N 为自编练习题"）。
- **Griffiths 原书题**单独放在"Griffiths 教材精选习题"小节，使用 `[G x.xx]` 标记，附上题目的物理背景说明和提示。
- **编程练习**至少1题，提供Python示例框架代码，使用 `matplotlib` 可视化。
- 自编题与 Griffiths 题**并存不冲突**，前者侧重概念构建，后者侧重考试对标。

### 内容撰写要点

1. **物理图景先于数学推导**：每个公式之前都应有直觉性的物理解释（"为什么应该是这个形式？"）。推导之后附上极限验证和物理含义。
2. **例题是骨架**：每个核心概念至少配一个完整的例题（含解题过程和结果验证）。例题的选取应与OUTLINE中强调的考试重点对齐。
3. **极限验证是必须的**：每个重要结果都应检查特殊情况（$r \to 0$, $r \to \infty$, 退化为已知结果等）。
4. **跨章节引用**：在引言和正文中大量使用"回忆第X章 §Y.Z"、"为第X章做铺垫"等前后呼应的语言，帮助学生建立知识网络。
5. **公式框（boxed）**：所有核心结论用 `$$\boxed{...}$$` 标注，方便学生快速定位。
6. **Mermaid 知识图谱**：在逻辑复杂的章节中插入 mermaid 图辅助理解。推荐场景：方法选择流程图（引言）、概念逻辑依赖图（理论节末尾）、操作步骤流程图（方法论节）、层级结构图（分类体系）、全景知识图谱（Key Takeaway 前）。

### PDF教材的使用技巧

- Griffiths PDF（628页）可通过 `PyPDF2` 库读取。注意该PDF的文字提取有字符粘连问题（如 `Problem1.13` 而非 `Problem 1.13`），搜索时需考虑两种格式。
- 往年试题PDF可用于确认考试重点，但文字提取质量不稳定，建议人工验证关键信息。

### 章节撰写经验

1. **考试重灾区需加大例题密度**：第3章（考试重灾区）例题15个；第5章（考试重灾区）例题19个；**第9章（期末考试压轴章节）例题13个**——波导、菲涅耳、布儒斯特角、色散是历年期末必考。
2. **物理图景中方向约定要统一**：涉及电流方向、磁力方向时，务必在例题开头明确坐标约定和右手定则的使用，避免正负号混淆。
3. **跨章节类比是高效教学工具**：第4章的"P→束缚电荷→D→线性介质"结构与第6章的"M→束缚电流→H→线性磁介质"完美平行。**第8章守恒律的"密度+流密度=源"模板可串起电荷、能量、动量、角动量四套守恒律**——一图统摄。
4. **编程练习的 streamplot 可视化效果好**：粒子轨迹模拟推荐 Magnetic Velocity Verlet 算法；坡印廷矢量、波导 TE 模式场分布用 streamplot 效果优秀。
5. **PDF读取用PyPDF2**：必须用 `PyPDF2.PdfReader` 读取Griffiths教材，注意字符粘连。
6. **自编题与Griffiths题互补**：自编题侧重概念构建，Griffiths题侧重考试对标。
7. **深入选学用引用块标注**："🔬 深入选学"标记块供读者选择性学习。
8. **期中/期末试题逆向对标很重要**：撰写前务必先读完往年试题，对应期中/期末重灾区设计直接命中的例题。
9. **守恒律章节（第8章）的物理图景比数学更重要**：坡印廷定理用电阻丝、平行板电容器两个例题足以建立"能量从场中流入"的革命性图像；麦克斯韦应力张量用两半球磁吸力即可；隐藏动量+Dirac 磁单极量子化是绝佳的"压轴震撼"。
10. **波动章节（第9章）需明确 SI 单位制和复数记号约定**：复数记号 $e^{i(kz-\omega t)}$ vs $e^{-i(\omega t - kz)}$ 不同教材约定不同。本教程统一采用 $e^{i(kz-\omega t)}$（与 Griffiths 一致）；能流、辐射压等非线性运算必须取实部后再算。
11. **波导例题必须覆盖 TE/TM 完整流程**：从分离变量、边界条件、本征模、截止频率到群相速度，必须写一个"标准模板例题"（第9章例题 9.12-9.13），考试时填参数即可解。
12. **辐射章节（第11章）必须有的"四大支柱例题"**：① 振荡电偶极子完整推导（势→场→功率）；② 旋转偶极子（$1+\cos^2\theta$ 角分布 + 极轴圆偏振 + 赤道线偏振，直接对标老期末第5题）；③ 玻尔氢原子寿命（$\tau = a_0^3/(4 r_e^2 c)\approx 1.6\times 10^{-11}$ s，直接对标新期末第4题）；④ 同步辐射 LEP 每圈损失（直线 vs 回旋的 $\gamma^4$/$\gamma^6$ 对比）。这四题就是期末高分关键。
13. **抗中断撰写策略（第10章验证有效）**：先 Write 一个完整骨架文件（含所有节标题与 `[PLACEHOLDER-XXX]` 占位符），再用 Edit 工具逐节替换占位符。每节写完即落盘，避免一次性 Write 长内容时 API socket 中断丢失。第10章用此法 7 次 Edit 完成 1137 行。
14. **势与场章节（第10章）的两个"教学陷阱"**：① $\mathbf{E}\neq -\nabla V$，必须含 $-\partial\mathbf{A}/\partial t$（学生最常漏）；② Liénard-Wiechert 几何因子 $1/(1-\hat{\boldsymbol{\mathcal{r}}}\cdot\mathbf{v}/c)$ **不是洛伦兹收缩**，是"信号收集效应"——Griffiths §10.3.1 "火车类比"教学最佳。

### Cheating Paper 撰写经验（针对 `附录 公式速查.md`）

1. **用户最看重二级结论**：考场上最有用的是"看到题型直接套结论"，不是公式推导。每个二级结论用 🔴 emoji + boxed 公式醒目标注。
2. **必须有"二级结论速查表"独立一章**：把 23+ 题型的关键结论集成一张表（Part 7）。考场翻一页就能定位。
3. **答题 SOP 模板独立成章**：题型分流（高斯/镜像/分离变量/多极）写成决策树文字流程图（Part 8）。
4. **易错点要枚举**：用 ⚠️ 标记，写在末尾（Part 9）。这一步是从"考前速通.md"中提炼用户实际踩过的坑。
5. **"一页式临场默写清单"必备**：进考场前默写一遍能写出的就不会忘，作为最后一章（Part 10）。
6. **整合而非续写**：用户在 MISSION.md 写"接着已有的写就行，或者整合"，但实际整合更优——已有第6章内容融入到 Part 5 中即可，全文应全章节统一结构。
7. **素材来源优先级**：往年试题（期中/期末）→ 习题课 PDF → 当前作业（HW-X）→ Griffiths 教材。**习题课 PDF 是二级结论的金矿**（如长电缆自感、磁像法、铁芯气隙、Clausius-Mossotti、德拜屏蔽都源自习题课）。
8. **善用"考前速通.md"**：用户已有的"考前速通.md"是非常好的素材库（在`往年试题/`下），cheating paper 是其结构化、紧凑化的升级版。两者并存：考前速通详解推导，cheating paper 速查二级结论。
